# DSA — Phase 1: Basics (Weeks 1–2)

**Budget:** ~30 hrs (≈2.5–3h/day) · **Goal:** Comfort with complexity, arrays/strings, hashing, recursion.
**Target:** 25–30 problems (mostly easy, some medium).

> Habit for every problem — write 4 lines: **Pattern · Clue · Time/Space · Missed edge case.**

---

## ✅ Topics & hours

### 1. Complexity analysis — 3h
- [ ] Big-O, Big-Theta, Big-Omega (intuition)
- [ ] Time & space of common operations
- [ ] Analyzing loops & recursion

### 2. Arrays & Strings — 10h
- [ ] Traversal, prefix/suffix, in-place operations
- [ ] Reverse/rotate array & string
- [ ] Two-sum (hashmap), frequency counting
- [ ] Kadane's (max subarray), running sum
- [ ] Practice: 12–14 problems

### 3. Hashing — 6h
- [ ] `HashMap`/`HashSet` usage patterns
- [ ] Anagrams, duplicates, first unique, group by key
- [ ] Practice: 6–8 problems

### 4. Basic recursion — 6h
- [ ] Base case + recursive case thinking
- [ ] Factorial, Fibonacci, power, sum of digits
- [ ] Recursion tree & stack understanding
- [ ] Practice: 5–6 problems

### 5. Sorting basics — 5h
- [ ] Built-in sort, `Comparator`
- [ ] Bubble/selection/insertion (understand), merge/quick (concept)
- [ ] When sorting helps (then two-pointer/binary search)
- [ ] Practice: 3–4 problems

---

## 📝 Suggested starter problem list (LeetCode)
- Two Sum, Best Time to Buy/Sell Stock, Contains Duplicate
- Valid Anagram, Group Anagrams, Maximum Subarray
