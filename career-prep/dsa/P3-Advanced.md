# DSA — Phase 3: Trees, Graphs, Heaps, DP Basics (Weeks 7–10)

**Budget:** ~75 hrs · **Goal:** Clear medium/hard rounds with structured thinking.
**Target:** 75–85 problems.

---

## ✅ Topics, hours & targets

### 1. Trees / BST — 18h · 20 problems
- [ ] Traversals: preorder/inorder/postorder (recursive + iterative), level-order (BFS)
- [ ] Height, diameter, balanced check, max path sum
- [ ] BST: validate, insert/delete, kth smallest, LCA
- [ ] Views (left/right/top), serialize/deserialize
- [ ] Construct tree from traversals
- **Clue:** hierarchical data, recursion on subtrees

### 2. Heap / Priority Queue — 10h · 12 problems
- [ ] Min-heap/max-heap, `PriorityQueue` usage
- [ ] Kth largest/smallest, top-K frequent
- [ ] Merge k sorted lists, median from data stream
- [ ] Task scheduling problems
- **Clue:** "top/kth/most frequent", streaming, scheduling

### 3. Graphs — 16h · 18 problems
- [ ] Representations (adj list/matrix)
- [ ] BFS/DFS traversal, connected components
- [ ] Cycle detection (directed/undirected)
- [ ] **Topological sort** (Kahn's + DFS)
- [ ] Shortest path: Dijkstra, BFS on unweighted, Bellman-Ford (concept)
- [ ] **Union-Find (DSU)** — connected components, Kruskal
- [ ] Grid problems (islands, rotting oranges, flood fill)
- **Clue:** nodes+edges, dependencies, reachability, grids

### 4. Backtracking — 8h · 10 problems
- [ ] Subsets, permutations, combinations, combination sum
- [ ] N-Queens, Sudoku (concept), word search
- [ ] Pruning strategies
- **Clue:** "all possible", explore + undo choices

### 5. Dynamic Programming (starter) — 18h · 20 problems
- [ ] 1D DP: climbing stairs, house robber, jump game, coin change
- [ ] 2D DP: unique paths, grid min path, LCS, edit distance
- [ ] Knapsack pattern (0/1, subset sum, partition equal subset)
- [ ] DP on strings/subsequences
- [ ] Memoization → tabulation → space optimization
- **Clue:** overlapping subproblems + optimal substructure; "count ways / min-max"
