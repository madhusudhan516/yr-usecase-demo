# DSA — Phase 4: Interview Mode (Weeks 11–12)

**Budget:** ~40 hrs · **Goal:** Convert knowledge into performance under time pressure.
**Target:** 30–40 mixed problems · 80% medium solve rate under time.

---

## ✅ Activities & hours

### 1. Timed problem sets — 16h
- [ ] 3 timed sets/week (2 problems each, 45–60 min)
- [ ] Mix all patterns (arrays, DP, graphs, trees, heap)
- [ ] Simulate real constraints: no editorial for 25 min
- [ ] Post-set review: what pattern, where you stalled

### 2. Mock interviews — 12h
- [ ] 2 coding mocks/week (think-aloud)
- [ ] Structure: clarify → examples → brute force → optimize → complexity → code → test
- [ ] Platforms: Pramp, interviewing.io, peer, AI mock
- [ ] Record & review communication

### 3. Weak-area re-solve — 8h
- [ ] Re-solve everything in your "repeat mistakes" log
- [ ] Redo hardest 2 topics from Phase 2 & 3
- [ ] Spaced repetition: re-solve day 1, day 3, day 7

### 4. Speed & templates — 4h
- [ ] Memorize clean templates: binary search, BFS/DFS, DSU, sliding window, Dijkstra, DP tabulation
- [ ] Practice writing bug-free code fast
- [ ] Edge cases checklist (empty, single, duplicates, overflow, negatives)

---

## 🧠 Interview execution framework (say this out loud)
1. **Clarify** inputs, outputs, constraints, edge cases
2. **Examples** — walk a small case
3. **Brute force** — state it + complexity
4. **Optimize** — identify pattern, improve
5. **Code** — clean, named variables, modular
6. **Test** — dry run + edge cases
7. **Complexity** — final time/space

## 🎯 Phase 4 exit criteria (interview-ready)
- [ ] Solve random mediums in ~30 min, think-aloud
- [ ] 8–10 mocks done with feedback applied
