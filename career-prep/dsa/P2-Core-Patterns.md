# DSA — Phase 2: Core Interview Patterns (Weeks 3–6)

**Budget:** ~70 hrs · **Goal:** Master the patterns that appear in most interviews.
**Target:** 75–80 problems.

---

## ✅ Patterns, hours & targets

### 1. Two Pointers — 10h · 12 problems
- [ ] Opposite ends (pair sum, container water)
- [ ] Same direction (remove dups, partition)
- [ ] Palindrome checks, merge-style scans
- **Clue:** sorted array / pair / in-place / triplets

### 2. Sliding Window — 12h · 15 problems
- [ ] Fixed window (max sum size k)
- [ ] Variable window (longest/shortest with condition)
- [ ] Window + hashmap (longest substring, anagrams)
- **Clue:** contiguous subarray/substring + optimize

### 3. Binary Search — 10h · 12 problems
- [ ] Classic search, lower/upper bound
- [ ] Rotated array, first/last occurrence
- [ ] **Binary search on answer** (min/max feasible value)
- **Clue:** sorted / monotonic / "minimize the maximum"

### 4. Stack & Queue — 12h · 15 problems
- [ ] Valid parentheses, min stack
- [ ] **Monotonic stack** (next greater/smaller element)
- [ ] Largest rectangle histogram, daily temperatures
- [ ] Queue/Deque (sliding window maximum)
- **Clue:** nearest greater/smaller, nested structure

### 5. Linked List — 10h · 12 problems
- [ ] Reverse (iter & recursive), middle node
- [ ] **Fast/slow pointers** (cycle detection, cycle start)
- [ ] Merge two lists, remove nth from end
- [ ] Reorder, palindrome linked list
- **Clue:** pointer manipulation, cycle, k-th from end

### 6. Prefix Sum + Intervals — 10h · 10 problems
- [ ] Prefix/suffix sums, subarray sum equals k
- [ ] Difference array concept
- [ ] Merge intervals, insert interval, meeting rooms
- **Clue:** range queries, overlapping ranges
