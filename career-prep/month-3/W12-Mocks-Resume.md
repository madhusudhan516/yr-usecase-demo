# Week 12 — Mock Interviews + Resume + Applications

**Month:** 3 · **Total budget:** ~25 hrs · **Goal:** Convert preparation into offers. Package everything.

> Deliverable: **interview kit** — resume, project docs, STAR stories, GitHub portfolio.

---

## ✅ Sub-topics & hours

### 1. Mock interviews — 10h
- [ ] 4 DSA mocks (timed, think-aloud, brute→optimal→complexity)
- [ ] 3 system design mocks (LLD + HLD mix)
- [ ] 2 behavioral mocks
- [ ] Platforms: Pramp, interviewing.io, peers, ChatGPT/AI mock
- [ ] Record yourself; review clarity & structure

### 2. Resume rewrite (impact-first) — 4h
- [ ] 1 page, reverse-chronological, ATS-friendly
- [ ] Bullets = Action + Tech + **Quantified impact**
  - "Reduced API p95 latency by 35% via Redis cache-aside + DB index tuning"
  - "Designed Kafka async pipeline improving throughput 2.5x"
  - "Cut deployment time 40→12 min with Jenkins CI/CD"
- [ ] Tailor keywords to each JD (Java, Spring, microservices, AWS, Kafka)
- [ ] Link flagship GitHub + live demo

### 3. GitHub portfolio polish — 4h
- [ ] Flagship repo README: architecture diagram, tech, run steps, tradeoffs
- [ ] Clean commits, tests visible, CI badge
- [ ] Pin best repos; write a short case-study doc

### 4. Behavioral / STAR prep — 4h
- [ ] 8 STAR stories: scaling win, incident/on-call, cross-team delivery, hard tradeoff, prod bug root-cause, conflict, mentoring, failure+learning
- [ ] Map to Apple values: collaboration, ownership, quality, innovation, attention to detail
- [ ] Practice concise 2-min delivery

### 5. Applications & referrals — 3h
- [ ] Target list: Apple + Uber, Atlassian, Amazon, Microsoft, Walmart Global Tech, Adobe, Stripe-like
- [ ] Get referrals (LinkedIn alumni, ex-colleagues)
- [ ] Optimize LinkedIn (headline, about, projects)
- [ ] Track applications (see tracker below)
